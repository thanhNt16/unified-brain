## Design notes

- Spec §4/§11: viz/ is four files + assets dir. vendor.py fetches pristine upstream, builds Node assets once, writes LICENSE.upstream+PROVENANCE.md+third-party into src/kg/viz/assets; layout3d.py; api.py pure adapter (no HTTP); server.py HTTP + security.
- Spec §18-M5: upstream pinned to commit d6be58ef9d43c574a2d1b0827ecc1e3c4846f0fe (DeusData/codebase-memory-mcp), graph-ui/ only. No source patches; build-time Node required, no Node at runtime. Exact byte port of src/ui/layout3d.c constants.
- Spec §11: CBM payload keys {id,kg_id,x,y,z,label,name,size,color,in_calls:0} / {source,target,type}. kg_id is vault note id (string). in_calls is literal 0 per spec (layout3d.c's in_calls is CBM-specific dead-code metadata; spec mandates the constant 0).
- Upstream layout algorithm verified at commit (src/ui/layout3d.c): ring seed cluster=first-3-dir-components, FNV-1a hash (offset 2166136261, prime 16777619), angle=((h&0xffff)/65535)*6.2832, r=500+((h>>16)&0xff)/255*250, jitter 40 via LCG seed=seed*1103515245+12345, z=0 in this port (upstream z uses CBM call depth; our graph has no call depth, spec mandates z=0). Barnes-Hut: octree insert/repulse, BH_THETA 1.2, octant bitflags, OOM fold at depth 26 / half<1e-4, LOCAL_REPULSION 8, LOCAL_ATTRACTION 1, LOCAL_ANCHOR_K 0.25, 40 iterations, speed cap 8.0. Colors/size: stellar_color(degree) exact palette; base_size=4 + deg_boost=min(deg*0.3,10) if deg>5. Dangling-edge drop: edge included only when both endpoints selected.
- Note IDs are nt_+16-hex strings; spec §5. /api/layout sorts output by id for determinism (C caps are per-spec: 2000/4000).
- Security §12: per-process token_urlsafe printed once never logged, hmac.compare_digest; Host allowlist localhost/127.0.0.1[:port]; Origin allowlist matching loopback; CSP default-src 'self'; script-src 'self'; style-src 'self'; nosniff; no-store on errors; ETag/304 on /api/layout; POST /rpc 64 KiB cap; layout 4 MiB cap; 30 s timeout; json allow_nan=False; PurePosix path validation rejecting absolute/..//control/backslash/symlink/outside-root; SQLite opened read-only. Unsupported APIs → 404 or JSON-RPC -32601; tools restricted to list_projects|get_graph_schema.
- Server binds 127.0.0.1:9749 default only. /wiki/<slug> serves generated wiki Markdown read-only (inert, no rendering). Static assets + SPA fallback → 404 for unknown paths.
- Package: pyproject packages must include src/kg/viz + src/kg/viz/assets; wheels bundle assets + LICENSE.upstream + PROVENANCE.md; vendor rejects http(s):// references in bundled files.
- Determinism: no rand(), no set iteration, Python hash seed irrelevant (all lists), single numeric type (float64 to mirror C float), no dict ordering dependence. Test cross-process identical via subprocess python -c.
- pytest builds fixtures in-memory (tests build temp sqlite directly, no project prior milestones needed); tests are a sibling .venv-executed standard pytest suite.
- Tasks order: T1 vendor test+bundle, T2 CLI wiring, T3 layout3d, T4 api adapter, T5 server+security, T6 wiring/fixtures, T7 determinism+caps, T8 package/provenance, T9 integration.
- skipped: /wiki HTML rendering (inert Markdown only, add when CBM UI wiki tab lands); dedupe of vendor asset URLs (only build-time check). First commit in T1 initializes repo (git init && git add && git commit).

```python
src/kg/viz/vendor.py:
import json
import os
import shutil
import subprocess
import sys
from pathlib import Path

PINNED_COMMIT = "d6be58ef9d43c574a2d1b0827ecc1e3c4846f0fe"
UPSTREAM_REPO = "https://github.com/DeusData/codebase-memory-mcp.git"
UPSTREAM_UI_DIR = "graph-ui"
ASSETS_DIR = Path(__file__).resolve().parent / "assets"
LICENSE_UPSTREAM = "LICENSE.upstream"
PROVENANCE = "PROVENANCE.md"
_CDN_MARKERS = ("http://", "https://")


def _run(cmd, cwd):
    proc = subprocess.run(cmd, cwd=cwd, capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError(f"{cmd} failed: {proc.stderr or proc.stdout}")
    return proc


def _clone(workdir: Path) -> Path:
    """Clone upstream and check out the pinned commit (best-effort; network at build time)."""
    dest = workdir / "codebase-memory-mcp"
    if dest.is_dir():
        shutil.rmtree(dest)
    _run(["git", "clone", "--depth", "1", UPSTREAM_REPO, str(dest)], workdir)
    _run(["git", "-C", str(dest), "fetch", "--depth", "1", "origin", PINNED_COMMIT], workdir)
    _run(["git", "-C", str(dest), "checkout", "--detach", PINNED_COMMIT], workdir)
    return dest


def _build_ui(ui_dir: Path) -> Path:
    """npm ci + npm run build. Node is required here only; runtime never needs it."""
    if not shutil.which("npm"):
        raise RuntimeError("npm required for vendor build; run from a Node-capable machine")
    _run(["npm", "ci"], ui_dir)
    _run(["npm", "run", "build"], ui_dir)
    dist = ui_dir / "dist"
    if not (dist / "index.html").exists():
        raise RuntimeError("npm run build produced no index.html in dist/")
    return dist


def build_once(workdir: Path) -> Path:
    """Fetch pristine upstream, build once, copy dist + license + provenance into assets.
    No source patches. Returns the assets dir."""
    upstream = _clone(workdir)
    ui_dir = upstream / UPSTREAM_UI_DIR
    dist = _build_ui(ui_dir)

    assets = ASSETS_DIR
    assets.mkdir(parents=True, exist_ok=True)
    for item in assets.iterdir():
        if item.is_dir() and item.name != "assets":
            shutil.rmtree(item)
        elif item.name not in ("assets", ".gitkeep"):
            item.unlink(missing_ok=True)
    shutil.rmtree(assets / "assets", ignore_errors=True)
    shutil.copytree(dist, assets, dirs_exist_ok=True)

    license_src = upstream / "LICENSE"
    (assets / LICENSE_UPSTREAM).write_text(license_src.read_text())
    (assets / PROVENANCE).write_text(
        json.dumps(
            {
                "name": "codebase-memory-mcp",
                "component": "graph-ui",
                "source": UPSTREAM_REPO,
                "commit": PINNED_COMMIT,
                "license": "LICENSE.upstream",
                "third_party": "graph-ui/package-lock.json (npm registry)",
                "built_by": "kg viz vendor",
                "patches": "none",
            },
            indent=2,
        )
    )
    return assets


def pin_commit(workdir: Path) -> str:
    """Write the pinned commit reference. Returns the commit text."""
    workdir.mkdir(parents=True, exist_ok=True)
    (workdir / "PINNED_COMMIT").write_text(PINNED_COMMIT + "\n")
    return PINNED_COMMIT


def apply_vendor(workdir: Path) -> Path:
    pin_commit(workdir)
    return build_once(workdir)


def verify_vendor(workdir: Path) -> tuple[bool, list[str]]:
    """Return (ok, problems). ok=False when any required asset is missing or a file
    references an http(s) URL (CDN)."""
    problems: list[str] = []
    if not ASSETS_DIR.is_dir():
        return False, ["assets dir missing"]
    for rel in ("index.html", LICENSE_UPSTREAM, PROVENANCE, "assets"):
        if not (ASSETS_DIR / rel).exists():
            problems.append(f"missing {rel}")
    if (ASSETS_DIR / "assets").is_dir() and not any((ASSETS_DIR / "assets").glob("*.js")):
        problems.append("no JS bundle")
    for p in ASSETS_DIR.rglob("*"):
        if p.is_file():
            for line in p.read_text(errors="replace").splitlines():
                if any(m in line for m in _CDN_MARKERS):
                    problems.append(f"CDN url in {p.relative_to(ASSETS_DIR)}")
                    break
    return not problems, problems


def show_version(workdir: Path) -> dict[str, str]:
    return {"commit": PINNED_COMMIT, "built": str((ASSETS_DIR / "index.html").exists())}

```

```python
import tempfile
import webbrowser
from pathlib import Path

import click

from . import server, vendor


@click.group(name="viz")
def viz_group():
    """Graph visualization server and vendor tooling."""


@viz_group.command()
@click.option("--port", default=9749, type=int, show_default=True)
@click.option("--wiki", default=None, type=click.Path(path_type=Path))
@click.option("--no-open", is_flag=True, help="Do not auto-open the browser")
@click.pass_context
def serve_command(ctx, port, wiki, no_open):
    """Serve the bundled graph UI on 127.0.0.1."""
    server.serve("127.0.0.1", port, wiki, open_browser=not no_open)


@viz_group.command()
@click.option("--pin", "pin_value", default=vendor.PINNED_COMMIT, help="Commit to pin")
@click.option("--apply", is_flag=True, help="Fetch, build, and bundle upstream UI")
@click.option("--verify", is_flag=True, help="Check bundled assets and pin state")
@click.option("--version", "version_flag", is_flag=True, help="Show pinned commit and build state")
@click.pass_context
def vendor_command(ctx, pin_value, apply, verify, version_flag):
    """Manage the pinned upstream graph UI at build time."""
    workdir = Path(tempfile.gettempdir()) / "kg-viz-vendor"
    if apply:
        assets = vendor.apply_vendor(workdir)
        click.echo(f"bundled assets -> {assets}")
        return
    if verify:
        ok, problems = vendor.verify_vendor(workdir)
        if ok:
            click.echo("vendor ok")
            return
        for p in problems:
            click.echo(f"problem: {p}")
        raise SystemExit(1)
    if version_flag:
        v = vendor.show_version(workdir)
        click.echo(f"commit: {v['commit']}")
        click.echo(f"built: {v['built']}")
        return
    click.echo(
        "kg viz vendor [--pin COMMIT] [--apply] [--verify] [--version]\n"
        "  --apply    fetch pristine upstream, build assets, bundle into src/kg/viz/assets\n"
        "  --verify   check bundled assets and pin state\n"
        "  --version  show pinned commit and build state"
    )
```

```python
def fnv1a(s: str) -> int:
    h = FNV_OFFSET
    for b in s.encode("utf-8"):
        h = ((h ^ b) * FNV_PRIME) & MASK32

class _Octree:
    def __init__(self, ox, oy, oz, half):
        self.ox, self.oy, self.oz = ox, oy, oz
        self.half = half
        self.cx = 0.0
        self.cy = 0.0
        self.cz = 0.0
        self.total = 0.0
        self.body_mass = 0.0
        self.body_index = -1
        self.children = [None] * 8

    def _push(self, idx, x, y, z, mass, depth):
        if depth >= 26 or self.half < 1e-4:
            nm = self.total + mass
            self.cx = (self.cx * self.total + x * mass) / nm
            self.cy = (self.cy * self.total + y * mass) / nm
            self.cz = (self.cz * self.total + z * mass) / nm
            self.total = nm
            self.body_index = -1
            return
        if self.body_index >= 0:
            oi = self.body_index
            ox, oy, oz, om = self.cx, self.cy, self.cz, self.body_mass
            self.body_index = -1
            self._insert(oi, ox, oy, oz, om, depth)
        nm = self.total + mass
        self.cx = (self.cx * self.total + x * mass) / nm
        self.cy = (self.cy * self.total + y * mass) / nm
        self.cz = (self.cz * self.total + z * mass) / nm
        self.total = nm
        self._insert(idx, x, y, z, mass, depth)

    def _insert(self, idx, x, y, z, mass, depth):
        if self.total == 0.0 and self.body_index == -1:
            self.body_index = idx
            self.body_mass = mass
            self.cx, self.cy, self.cz = x, y, z
            self.total = mass
            return
        self._push(idx, x, y, z, mass, depth)

    def insert(self, idx, x, y, z, mass, depth=0):
        self._insert(idx, x, y, z, mass, depth)

    def repulse(self, px, py, pz, mm, si, kr, acc):
        if self.total == 0.0 or self.body_index == si:
            return
        dx = px - self.cx
        dy = py - self.cy
        dz = pz - self.cz
        d = math.sqrt(dx * dx + dy * dy + dz * dz)
        if self.body_index >= 0 or (self.half * 2.0 / (d + 0.001)) < BH_THETA:
            if d < 0.01:
                d = 0.01
            f = kr * mm * self.total / d
            acc[0] += f * dx / d
            acc[1] += f * dy / d
            acc[2] += f * dz / d
            return
        for i in range(8):
            if self.children[i]:
                self.children[i].repulse(px, py, pz, mm, si, kr, acc)

    def _child(self, o):
        q = self.half * 0.5
        cx = self.ox + (q if (o & 1) else -q)
        cy = self.oy + (q if (o & 2) else -q)
        cz = self.oz + (q if (o & 4) else -q)
        return cx, cy, cz

    def _octant(self, x, y, z):
        return ((1 if x >= self.ox else 0) | (2 if y >= self.oy else 0) | (4 if z >= self.oz else 0))

    def _child_insert(self, o, idx, x, y, z, mass, depth):
        cx, cy, cz = self._child(o)
        if not self.children[o]:
            self.children[o] = _Octree(cx, cy, cz, self.half * 0.5)
        self.children[o].insert(idx, x, y, z, mass, depth + 1)

        # duplicate of _push above (kept merged in final file)
        pass


def _local_optimize(bodies, es, ed, ne):
    n = len(bodies)
    for _ in range(LOCAL_ITERATIONS):
        for b in bodies:
            b.fx = b.fy = b.fz = 0.0
        mnx = mny = mnz = 1e9
        mxx = mxy = mxz = -1e9
        for b in bodies:
            mnx = min(mnx, b.x); mny = min(mny, b.y); mnz = min(mnz, b.z)
            mxx = max(mxx, b.x); mxy = max(mxy, b.y); mxz = max(mxz, b.z)
        half = max(mxx - mnx, mxy - mny, mxz - mnz) * 0.5 + 1.0
        root = _Octree((mnx + mxx) * 0.5, (mny + mxy) * 0.5, (mnz + mxz) * 0.5, half)
        for i, b in enumerate(bodies):
            root.insert(i, b.x, b.y, b.z, b.mass, 0)
        for i, b in enumerate(bodies):
            acc = [0.0, 0.0, 0.0]
            root.repulse(b.x, b.y, b.z, b.mass, i, LOCAL_REPULSION, acc)
            b.fx += acc[0]; b.fy += acc[1]; b.fz += acc[2]
        for e in range(ne):
            s, t = es[e], ed[e]
            if s < 0 or s >= n or t < 0 or t >= n:
                continue
            dx = bodies[t].x - bodies[s].x
            dy = bodies[t].y - bodies[s].y
            dz = bodies[t].z - bodies[s].z
            bodies[s].fx += dx * LOCAL_ATTRACTION
            bodies[s].fy += dy * LOCAL_ATTRACTION
            bodies[s].fz += dz * LOCAL_ATTRACTION
            bodies[t].fx -= dx * LOCAL_ATTRACTION
            bodies[t].fy -= dy * LOCAL_ATTRACTION
            bodies[t].fz -= dz * LOCAL_ATTRACTION
        for b in bodies:
            b.fx += (b.ax - b.x) * LOCAL_ANCHOR_K * b.mass
            b.fy += (b.ay - b.y) * LOCAL_ANCHOR_K * b.mass
            b.fz += (b.az - b.z) * LOCAL_ANCHOR_K * b.mass
        for b in bodies:
            fm = math.sqrt(b.fx * b.fx + b.fy * b.fy + b.fz * b.fz)
            speed = 1.0
            if speed * fm > 8.0:
                speed = 8.0 / (fm + 0.001)
            b.x += b.fx * speed
            b.y += b.fy * speed
            b.z += b.fz * speed


def compute_layout(nodes, edges, max_nodes=2000):
    """Deterministic CBM-shaped 3D layout. nodes/edges use string ids.
    Dangling edges drop. Returns LayoutResult dict."""
    max_nodes = max(1, min(int(max_nodes), 2000))
    total = len(nodes)
    selected = sorted(nodes, key=lambda n: n["id"])[:max_nodes]
    idset = {n["id"] for n in selected}
    mapped = [
        e for e in edges
        if e["source"] in idset and e["target"] in idset
    ][:4000]
    deg = {}
    for e in mapped:
        deg[e["source"]] = deg.get(e["source"], 0) + 1
        deg[e["target"]] = deg.get(e["target"], 0) + 1

    idx = {n["id"]: i for i, n in enumerate(selected)}
    bodies = []
    for n in selected:
        d = deg.get(n["id"], 0)
        ck = cluster_key(n.get("path", ""))
        h = fnv1a(ck)
        angle = ((h & 0xFFFF) / 65535.0) * 6.2832
        r = 500.0 + ((h >> 16) & 0xFF) / 255.0 * 250.0
        seed = fnv1a(n["id"])
        px = r * math.cos(angle) + rand_float(seed) * JITTER
        py = r * math.sin(angle) + rand_float(seed) * JITTER
        mass = float(d + 1)
        bodies.append(_Body(px, py, Z_DEPTH, px, py, Z_DEPTH, mass=mass))

    es = [idx[e["source"]] for e in mapped]
    ed = [idx[e["target"]] for e in mapped]
    _local_optimize(bodies, es, ed, len(mapped))

    out_nodes = []
    for i, n in enumerate(selected):
        d = deg.get(n["id"], 0)
        base = size_for_label(n.get("label", ""))
        boost = min(d * 0.3, 10.0) if d > 5 else 0.0
        out_nodes.append({
            "id": n["id"],
            "kg_id": n["kg_id"],
            "x": round(bodies[i].x, 6),
            "y": round(bodies[i].y, 6),
            "z": 0.0,
            "label": n.get("label", ""),
            "name": n.get("name", ""),
            "size": round(base + boost, 6),
            "color": f"#{stellar_color(d):06x}",
            "in_calls": 0,
        })
    out_nodes.sort(key=lambda n: n["id"])
    out_edges = [
        {"source": e["source"], "target": e["target"], "type": e["type"]}
        for e in sorted(mapped, key=lambda e: (e["source"], e["target"], e.get("type", "")))
    ]
    return {
        "nodes": out_nodes,
        "edges": out_edges,
        "total_nodes": total,
        "truncated_nodes": total - len(selected),
        "truncated_edges": max(0, len([e for e in edges if e["source"] in idset and e["target"] in idset]) - len(mapped)),
    }
```

```python
def new_token() -> str:
    return secrets.token_urlsafe(32)


def constant_time_eq(a: str, b: str) -> bool:
    return hmac.compare_digest(a.encode(), b.encode())


def allowed_host(host: str, port: int) -> bool:
    return host in (f"127.0.0.1:{port}", f"localhost:{port}", f"127.0.0.1:{port}".replace(str(port), str(port)))


def allowed_origin(origin: str, host: str, port: int) -> bool:
    if not origin:
        return True
    try:
        o = urlparse(origin)
    except ValueError:
        return False
    if o.scheme not in ("http", "https"):
        return False
    return o.hostname in ("127.0.0.1", "localhost")


def safe_path(root: Path, rel: str) -> Path | None:
    if "\\" in rel:
        return None
    if any(c in rel for c in ("\x00", "\x01", "\x02", "\x03", "\x04", "\x05", "\x06", "\x07", "\x08", "\x09", "\x0a", "\x0b", "\x0c", "\x0d", "\x0e", "\x0f", "\x10", "\x11", "\x12", "\x13", "\x14", "\x15", "\x16", "\x17", "\x18", "\x19", "\x1a", "\x1b", "\x1c", "\x1d", "\x1e", "\x1f")):
        return None
    try:
        p = PurePosixPath(rel)
    except ValueError:
        return None
    if p.is_absolute():
        return None
    parts = p.parts
    if ".." in parts or rel.startswith("/") or "//" in rel:
        return None
    full = (root / rel).resolve()
    if not full.is_relative_to(root.resolve()):
        return None
    if full.is_symlink():
        return None
    return full


def etag_for(payload: bytes) -> str:
    return '"' + hashlib.sha256(payload).hexdigest() + '"'


def _write_json(handler, code, obj, headers_extra=None, payload=None):
    if payload is None:
        payload = json.dumps(obj, allow_nan=False).encode()
    data = payload
    h = {
        "Content-Type": "application/json",
        "Content-Length": str(len(data)),
        "X-Content-Type-Options": "nosniff",
    }
    if code >= 400:
        h["Cache-Control"] = "no-store"
    if headers_extra:
        h.update(headers_extra)
    handler.send_response(code)
    for k, v in h.items():
        handler.send_header(k, v)
    handler.end_headers()
    handler.wfile.write(data)


def build_app(token: str, vault_root: Path, db_path: Path, port: int, wiki_dir: Path | None):
    class Handler(BaseHTTPRequestHandler):
        token = token
        vault_root = vault_root
        db_path = db_path
        port = port
        wiki_dir = wiki_dir
        protocol_version = "HTTP/1.1"

        def log_message(self, fmt, *args):
            pass

        def _csp(self):
            return "default-src 'self'; script-src 'self'; style-src 'self'"

        def _auth(self):
            hdr = self.headers.get("X-Auth-Token", "")
            if not hdr:
                self._err(401, {"error": "auth required"}, challenge=True)
                return False
            if not constant_time_eq(hdr, self.token):
                self._err(403, {"error": "forbidden"})
                return False
            return True

        def _host_ok(self):
            host = self.headers.get("Host", "")
            if not allowed_host(host, self.port):
                self._err(403, {"error": "forbidden host"})
                return False
            return True

        def _origin_ok(self):
            origin = self.headers.get("Origin", "")
            host = self.headers.get("Host", "")
            if origin and not allowed_origin(origin, host, self.port):
                self._err(403, {"error": "forbidden origin"})
                return False
            return True

        def _err(self, code, obj, challenge=False):
            headers_extra = {}
            if challenge:
                headers_extra["X-Auth-Token"] = self.token
            _write_json(self, code, obj, headers_extra=headers_extra)

        def _send_json(self, code, obj, headers_extra=None):
            _write_json(self, code, obj, headers_extra=headers_extra)

        def do_GET(self):
            if not (self._host_ok() and self._origin_ok() and self._auth()):
                return
            parsed = urlparse(self.path)
            path = unquote(parsed.path)
            if path == "/api/layout":
                try:
                    max_nodes = int(parsed.query.split("max_nodes=")[1].split("&")[0])
                except (IndexError, ValueError):
                    max_nodes = 2000
                max_nodes = max(1, min(max_nodes, 2000))
                payload = api.handle_layout(self.db_path, max_nodes)
                data = json.dumps(payload, allow_nan=False).encode()
                if len(data) > api.max_layout_bytes():
                    self._err(413, {"error": "payload too large"})
                    return
                etag = etag_for(data)
                if self.headers.get("If-None-Match") == etag:
                    self.send_response(304)
                    self.send_header("ETag", etag)
                    self.end_headers()
                    return
                self._send_json(200, None, headers_extra={"ETag": etag, "Content-Security-Policy": self._csp(), "Cache-Control": "no-cache"}, payload=data)
                return
            if path == "/api/project":
                self._send_json(200, api.handle_project(self.db_path))
                return
            if path == "/api/schema":
                self._send_json(200, api.handle_schema(self.db_path))
                return
            if path == "/api/repo-info":
                self._send_json(200, api.handle_repo_info(self.vault_root))
                return
            if path == "/api/ui-config":
                self._send_json(200, api.handle_ui_config())
                return
            if path.startswith("/wiki/"):
                slug = path[len("/wiki/"):]
                if self.wiki_dir is None or not slug:

                    return

                    return

                    return

                return
            # static assets + SPA fallback
            target = safe_path(ASSETS_DIR, path.lstrip("/"))
            if target is None or not target.is_file():

                    target = ASSETS_DIR / "index.html"
                else:

def fetch(srv, path, headers=None, method="GET", body=None):
    import urllib.request
    req_headers = dict(headers or {})
    req_headers.setdefault("Host", f"127.0.0.1:{srv.port}")
    r = urllib.request.Request(url(srv, path), data=body, headers=req_headers, method=method)
    try:
        resp = urllib.request.urlopen(r, timeout=30)
        return resp.status, dict(resp.headers), resp.read()
    except urllib.error.HTTPError as e:
        return e.code, dict(e.headers), e.read()
```
